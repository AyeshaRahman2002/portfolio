# Artwork assets

Only genuine, approved artwork assets should be added here.

Add genuine, approved assets in these directories:

- `originals/` : primary artwork images
- `details/` : close crops and material details
- `process/` : documented stages of genuine work
- `textures/` : optional normal, roughness, and displacement maps

Prefer descriptive lowercase filenames and compressed WebP or AVIF derivatives.
Artwork metadata belongs in `data/portfolioData.ts`. Unknown titles, dates,
dimensions, descriptions, and process stages should be left undefined.
